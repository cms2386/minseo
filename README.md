💻 [2026-01] 나만의 C언어 소프트웨어 개발 프로젝트

1. 시나리오 제목
- 나만의 주차 요금 계산 프로그램

 2. 시나리오 (5~10줄)
- 해당 프로그램은 사용자가 입력한 주차 시간을 기반으로 총 주차 요금을 계산하는 교통 요금 계산 시스템입니다. 사용자는 차량 종류(일반차, 소형차)와 주차 시간(시간, 분)을 입력합니다. 시스템은 사용자가 입력한 시간을 토대로 전체 주차 시간을 분 단위로 변환하여 계산합니다. 

- 1시간까지는 기본 요금이 적용되며, 초과 시간에 대해서는 10분 단위로 추가 요금이 발생합니다. 또한, 차량 종류에 따라 요금이 달라지도록 설정하여 소형차의 경우 일정 비율의 할인이 적용되도록 설정했습니다.

- 최종적으로 계산된 주차 요금을 사용자에게 출력하며, 입력값과 계산 결과를 함께 보여줌으로써 프로그램의 흐름에 대한 이해가 용이하도록 구성하였습니다. 이 시스템은 조건문과 산술연산, 다양한 자료형을 활용하여 구현된 간단 요금 계산 프로그램입니다.


3. 예상 기능 및 메뉴 (최소 5개)
  1. 차량 종류 입력 기능 (일반차 / 소형차)
  2. 주차 시간 입력 기능 (시간 및 분 입력)
  3. 총 주차 시간 계산 기능 (시간에서 분으로 변환)
  4. 주차 요금 계산 기능 (기본 요금 + 추가 요금)
  5. 차량 종류에 따른 할인 적용 기능
  6. 최종 결과 출력 기능

🟦 [1차 과제: V1.0] 기초 뼈대 구축 (입출력과 변수)
 V1.0 개발 내용
• 사용자의 차량 종류, 주차 시간(시간, 분)을 입력하여 총 주차 요금을 계산하여 출력하는 프로그램입니다.
• 차량 종류(문자), 주차 시간(정수), 할인율(실수)을 활용하여 다양한 자료형을 적용했습니다.
• 주차 시간을 분 단위로 변환하고, 기본 요금과 추가 요금을 산술연산을 이용하여 계산하도록 구현했습니다.
• 조건문을 활용하여 일정 시간 초과 시 추가 요금을 적용하고, 소형차에 대한 할인 기능을 추가했습니다.

- 적용 내용: 교통 관련 프로그램(버스, 택시, 주차 등) 중 주차 요금 계산기를 선택하였고, 입력 → 계산 → 출력 구조를 토대로 프로그램을 설계하였다. 
또한 변수 5개 이상, 자료형 3개 이상, 산술연산 포함 등 과제 조건에 부합하도록 만족하도록 코드 구조를 구성함.

🛠️ Troubleshooting & 기술 회고
1. 문제 1: 문자 입력 시 이전 입력값으로 인해 입력이 제대로 되지 않는 문제가 발생.
   - 해결: scanf(" %c", &car_type); 와 같이 공백을 추가하여 버퍼 문제를 해결.

2. 문제 2: 주차 시간이 1시간 이하일 때 추가 요금이 잘못 계산되는 문제가 발생함.
   - 해결: if문을 사용하여 1시간 이하일 경우에 기본 요금만 적용하도록 조건을 분리함.

3. 문제 3: 시간과 분을 따로 입력받아 계산하는 과정이 처음에는 이해하기 어려웠음.
   - 해결: 시간에서 분으로 변환하는 공식을 적용해(total_minutes 계산) 문제를 해결하고 로직을 단순화시킴.
